C++

Welcome to C++! C++ is a general-purpose programming language that supports procedural, object-oriented, and other programming styles. It gives programmers control over how a program uses resources while providing tools for organizing code into reusable functions and classes.

Comments in C++

In C++, you can add comments (notes that aren't executed by the program, for others looking at your code to read) to your code using two different syntaxes:

  • Single-line comments start with two forward slashes (//) and continue to the end of the line.
  • Multi-line comments start with a forward slash and an asterisk (/*) and end with an asterisk and a forward slash (*/).

Variables

In C++, each variable has a declared type that determines what kind of value it can hold. C++ is statically typed, so the type is checked at compile time and a variable cannot be assigned a value of an incompatible type. Variables can be declared and initialized together, or declared first and assigned a value later.

Declaring Numbers

In C++, you declare a variable's type before assigning a number to it:

Int: int x = 5;

Decimal (double): double x = 5.0;

Declaring Strings

C++ strings are sequences of characters. The standard std::string type requires including the <string> header, and string values are enclosed in double quotes.

String: std::string x = "Hello, World!";

Note: Unlike Python, single quotes represent individual char values, not strings: char letter = 'A';

Declaring Booleans

Booleans in C++ represent the truth values true and false. Their values are lowercase, and variables are declared with the type bool.

True: bool x = true;

False: bool x = false;

Null Pointers

C++ uses nullptr to represent a pointer that does not point to an object. It is not a general-purpose null value for ordinary variables.

Null pointer: int* x = nullptr;

nullptr is not the same as 0 or an empty string; it means that the pointer does not point to an object.

Type Changing

C++ is statically typed, which means the type of a variable is declared and cannot be changed by assigning it a value of another type. You can convert a value to another type, though that conversion may change or lose information.

Widening: Converting a smaller numeric type to a larger one (e.g., int to double): double x = 5; stores the value as 5.0 instead of 5.

Narrowing: Converting a larger numeric type to a smaller one (e.g., double to int) may lose information. int x = static_cast<int>(5.8); truncates the decimal part, resulting in 5 and losing the .8.

Converting text to a number: int x = std::stoi("5"); (string to int) converts the string "5" to the integer 5. For decimal numbers, use std::stod("5.0") (string to double). These functions are available through the <string> header and can report errors if the text is not a valid number.

Input/Output

Input

C++ uses input and output streams. Include <iostream> at the top of a file to use std::cin for input and std::cout for output. To read a line of text, also include <string> and use std::getline:

#include <iostream>
#include <string>

std::string name;
std::cout << "What is your name? ";
std::getline(std::cin, name);

This displays "What is your name? ", reads a line from the user, and assigns that text to the string name variable. Since name is declared as a std::string, assigning another line of text to it later would replace its current value.

To read an integer, use the input operator >>:

int age;
std::cout << "What is your age? ";
std::cin >> age;

Static Output

The std::cout stream is used to display output to the user:

#include <iostream>

std::cout << "Hello, World!";

The above example will display the text "Hello, World!" to the user.

Note: use << for output operations, and >> for input operations.

Variable Output

You can also use std::cout to display the value of a variable:

#include <iostream>
#include <string>

std::string name = "Alice";
std::cout << name;

The above example will display the value of the variable name, which is "Alice".

Static + Variable Output

You can combine static text with variable values by sending each part to std::cout with the insertion operator <<:

#include <iostream>
#include <string>

std::string name = "Alice";
std::cout << "Hello, " << name << "!";

The above example will display "Hello, Alice!". Unlike Python f-strings, C++ output expressions send each text or variable value to the stream using <<.

Newlines

In C++, std::cout does not automatically add a newline at the end of each output operation. Use \n or std::endl to end a line:

std::cout << "Hello, World!\n";
std::cout << "How are you?" << std::endl;

This will display "Hello, World!" on one line and "How are you?" on the next line. std::endl also adds a newline.

You can use the \n escape sequence to insert a newline within a string:

std::cout << "Hello, World!\nHow are you?";

For long expressions, you can split a statement across multiple source lines; the compiler treats it as one statement until it reaches a semicolon:

int x = (
    number1
    + number2
);

In the above example, the expression spans several lines but is still one statement because a semicolon doesn't appear until the end.

C++ uses semicolons to end most statements. Whitespace and newlines separate tokens but do not, by themselves, end a statement.

Conditionals

Conditionals in C++ are used to execute different blocks of code based on certain conditions. The most common conditional statement is the if statement:

int age = 18;
if (age >= 18) {
    std::cout << "You are an adult.";
}

The above example will display "You are an adult." if age is greater than or equal to 18. C++ places the condition in parentheses and uses braces ({}) to mark the block. Unlike Python, a colon is not required after the condition.

Conditional Operators

C++ provides several comparison operators that can be used in conjunction with the if statement:

  • ==: Equal to
  • !=: Not equal to
  • >: Greater than
  • <: Less than
  • >=: Greater than or equal to
  • <=: Less than or equal to

Note that the equality operator uses two = signs. A single = assigns a value rather than comparing values:

int age = 18;
if (age == 18) {
    std::cout << "Age is 18";
}
age = 18;

In the above block, the condition checks if age is 18, while the last line sets age's value to 18. The assignment and comparison are separate statements.

Else and Else If Statements

C++ uses else and else if to handle multiple conditions:

int age = 17;
if (age >= 18) {
    std::cout << "You are an adult.";
} else {
    std::cout << "You are not an adult.";
}

The else block is executed if the condition in the if statement is false.

int score = 85;
if (score >= 90) {
    std::cout << "Grade: A";
} else if (score >= 80) {
    std::cout << "Grade: B";
} else {
    std::cout << "Grade: C";
}

The else if block allows you to check additional conditions if the previous conditions are false. When an if or else if condition is true, the rest of that conditional chain is skipped after its block executes.

Combining Conditions

C++ provides logical operators to combine multiple conditions:

  • &&: Both conditions must be true
  • ||: At least one condition must be true
  • !: Negates the condition
int age = 18;
bool has_license = true;
if (age >= 18 && has_license) { // checks if both statements are true
    std::cout << "You can drive.";
}

For the && operator, both conditions must be true for the block to execute. For the || operator, at least one condition must be true. The ! operator checks for falsity. You may combine these operators in different ways to create complex conditions.

Single-Statement If

If an if branch contains only one statement, braces may be omitted, although using braces is often clearer and helps prevent mistakes:

if (age >= 18)
    std::cout << "You are an adult.";

Ternary Operator

C++ provides a ternary operator for simple conditional expressions and assignments:

int age = 18;
std::string status = age >= 18 ? "adult" : "not adult";

The above example assigns "adult" to status if age is greater than or equal to 18; otherwise, it assigns "not adult". The ternary operator can also be used directly in a return statement:

std::string get_status(int age) {
    return age >= 18 ? "adult" : "not adult";
}

This function takes an age and returns the appropriate status based on the condition.

Switch Statements

C++ uses the switch statement to select between a limited set of constant values:

int status_code = 404;
switch (status_code) {
    case 200:
	   std::cout << "OK";
	   break;
    case 404:
	   std::cout << "Not Found";
	   break;
    default:
	   std::cout << "Unknown Status";
}

The switch statement checks status_code and jumps to the matching case. Each break exits the switch; without it, execution continues into the following case. The default case handles values not listed. A switch is best for a limited set of discrete values; use if/else if for more complex conditions.

Loops

Loops are used to execute a block of code repeatedly. C++ provides different kinds of loops, for example for and while loops.

Range-Based For Loop

A range-based for loop iterates over the elements in a sequence, such as a collection or string:

#include <iostream>
#include <string>

std::string fruits[] = {"apple", "banana", "cherry"};
for (const std::string& fruit : fruits) {
    std::cout << fruit << "\n";
}

In simpler terms, this says "for each fruit in the sequence of fruits, print that specific fruit before moving on to the next one." The loop variable fruit takes on each element's value during an iteration. It can technically have another name, but descriptive names make code easier to understand.

Example of a bad loop variable name:

for (const std::string& x : fruits) {
    std::cout << x << "\n";
}

For Loop with a Counter

A traditional for loop can repeat a block while counting through a range of numbers:

for (int i = 0; i < 5; i++) {
    std::cout << i << "\n";
}

This prints the numbers 0 through 4. The three parts of the loop header initialize i, check the condition before each iteration, and increment i after each iteration. The stop value 5 is not printed because the condition is i < 5. You can change the starting value and increment:

for (int i = 2; i < 10; i += 2) {
    std::cout << i << "\n";
}

This prints 2, 4, 6, and 8, counting up to 10 (not including 10) in steps of 2.

While Loop

The while loop executes a block repeatedly as long as its condition is true:

int i = 0;
while (i < 5) {
    std::cout << i << "\n";
    i++;
}

This is basically saying: "while i is less than 5, print the value of i, then increase it by 1." The variable must be initialized before the loop and updated so the loop can eventually end.

Loop Control Statements

C++ provides control statements to manage the flow of loops:

  • break: Terminates the loop immediately.
  • continue: Skips the rest of the current iteration and moves to the next one.
for (int num = 1; num < 10; num++) {
    if (num == 3) {
	   continue;
    }
    if (num == 6) {
	   break;
    }
    std::cout << num << "\n";
}

The loop starts with num equal to 1 and prints 1, 2, 4, and 5. continue skips 3, and break ends the loop when num reaches 6. The condition num < 10 means the loop stops before 10, though since it breaks at 6, it wouldn't reach 10 anyway.

Functions

Functions in C++ are used when you expect to use certain blocks of code multiple times, but with different arguments each time. They are declared with a return type, a name, and parentheses containing any parameters. A function declared with void does not return a value.

Functions Without Parameters

Functions without parameters have an empty set of parentheses:

#include <iostream>

void greet() {
    std::cout << "Hello, World!";
}

The above creates a function called greet that prints "Hello, World!" when it is called. In C++, the empty parentheses indicate that it takes no arguments.

Functions with Parameters

If you want a function to change its output based on input, define parameters in the parentheses of its declaration:

Parameters are the variables defined in a function signature; arguments are the values passed to the function when it is called.

#include <iostream>
#include <string>

void greet(const std::string& name) {
    std::cout << "Hello, " << name << "!";
}

In the above block, the function is named greet, and name is its parameter. A function call must provide an argument for each required parameter. Here, greet uses name to build its output.

To call a function, use its name followed by parentheses containing any required arguments:

greet("Alice");  // Output: Hello, Alice!

This calls the greet function and passes the string "Alice" as the name argument. In other words, it sends the string to greet and uses it as the value of the name parameter.

You can call a function multiple times with different arguments; each call runs independently:

greet("Alice");  // Output: Hello, Alice!
greet("Bob");    // Output: Hello, Bob!

You can also store an argument in a variable and pass that variable to the function:

std::string name = "Alice";
greet(name);  // Output: Hello, Alice!

Return

Return statements send a value back to the caller. The function's declared return type must match the type of the returned value:

int add(int a, int b) {
    return a + b;
}

The add function takes two parameters, a and b, and returns their sum. You can assign the returned value to a variable or use it directly in an expression:

int result = add(3, 5);  // the variable result is now 8
std::cout << add(3, 5);  // Output: 8

Classes and Objects

In C++, functions package reusable behavior, while classes define a kind of object and provide a way to create instances of it. A class is a blueprint for creating objects, while an object is an instance of a class. For example, you could have a class named Dog and create a Dog object called my_dog:

#include <string>

class Dog {
public:
    std::string name;
    std::string breed;

    Dog(const std::string& name, const std::string& breed) // this line is the constuctor
	   : name(name), breed(breed) {}
};

Dog my_dog("Doge", "Shiba Inu");

The Dog class has a constructor that initializes each Dog object with a name and breed field. The my_dog object is an instance of the Dog class, initialized with the name "Doge" and breed "Shiba Inu". In other words, all Dogs have a name and breed, which you pass as arguments when you create an instance (object) of the class.

Each Dog object has its own name and breed values. You could create a Dog named Bobby that is a golden retriever, or another named Scout that is a corgi.

A member function (often called a method) is a function that belongs to a class. C++ also allows standalone functions that do not belong to a class.

In a C++ constructor, the member initializer list after the colon initializes the object's fields from the constructor parameters. Here, name(name) initializes the object's name field from the parameter named name. The fields and parameters are distinct even though they share a name.

Classes and objects are a foundation of object-oriented programming (OOP) in C++. They can help keep related data and behavior organized.

Summary + Combined Examples

Now let's combine each concept we've learned into one code block. Let's say that I want to create a program that will be used to manage a character in a fantasy game, keeping track of their health, mana, and what would happen if they got attacked.

You can click on the comparison buttons to see how the syntax differs between C++ and the other languages on this site.

#include <iostream>
#include <string>

// Creating a class:
class Character {
public:
    std::string name;
    int health;
    int mana;

    Character(const std::string& name, int health, int mana) // uses a constructor to initialize the Character object with a name, health, and mana. What their name is and how much health and mana they have will be decided when we create the character by passing arguments to the constructor.
        : name(name), health(health), mana(mana) {}

// Creating a method (a function within a class):
    void take_damage(int damage) {
        this->health -= damage; // this line reduces the Character's health by the amount of damage taken. The -= operator is a shorthand for this->health = this->health - damage.
    }
};

// Creating a function:
void heal(Character& character, int amount) {
    character.health += amount; // this line increases the character's health by the specified amount.
}

int main() { // main is the entry point of the program. It is where the program starts executing.
// Declaring a variable:
    int takeThisMuchDamage = 0;

// Creating an object using a class:
    Character player1("Alice", 100, 50);

// Input:
    std::cout << "How much damage should the character take? ";
    std::cin >> takeThisMuchDamage; // we use std::cin to get user input as an integer and assign it to takeThisMuchDamage. For this example, assume the user enters a valid number >= 0.

// Calling an object's method, using the variable we declared earlier:
    player1.take_damage(takeThisMuchDamage);

// Function call:
    heal(player1, 20);

// Output:
    std::cout << player1.name << " has " << player1.health << " health and " << player1.mana << " mana.\n";

// Conditional:
    if (player1.health > 10) {
        std::cout << "Congrats! " << player1.name << " is still alive!\n"; // if the character's health is more than 10, this will trigger and the rest of the if/else if/else block will be skipped.
    } else if (player1.health > 0) { // this will trigger if the character's health is greater than 0 but not greater than 10.
        std::cout << player1.name << " is critically injured. Be Careful!\n";
    } else {
        std::cout << "Your character has died. Game over.\n"; // this will trigger at any point where health is less than or equal to 0, since all other possible health amount conditions have already been checked.
    }

// Loops:
    // Let's say that the character is poisoned, and will take damage over time:
    if (player1.health > 0) {
        while (player1.health > 0) { // while the character's health is greater than 0, this loop will continue to run.
            player1.take_damage(5); // the character takes 5 damage each iteration of the loop.
            std::cout << player1.name << " takes 5 poison damage and now has " << player1.health << " health.\n"; // this output occurs each time the loop repeats.
        }
        std::cout << "Your character has died from the poison.\n"; // this line runs after the loop ends because the loop condition is no longer true.
    }

    return 0; // we return 0 to indicate that the program has completed successfully. In C++, returning 0 from main is a convention that indicates success, while returning a non-zero value can indicate an error or abnormal termination.
}

Let's explain what we did above:

  1. We created a Character class with a name, health, and mana.
  2. We made a member function inside the class so that any Character could take damage.
  3. We created a heal function that increases a character's health by the amount passed in when called.
  4. We declared and initialized the variable takeThisMuchDamage so that we could assign it a value later based on user input. In C++, the variable has a declared type and must be initialized before its value is read.
  5. We created a Character object named player1, with the name "Alice", 100 health, and 50 mana.
  6. We took input from the user and assigned it to takeThisMuchDamage.
  7. We called the take_damage member function on player1, using the amount specified by the user's input.
  8. We called the heal function to heal player1 by 20.
  9. We displayed player1's current health and mana.
  10. We used a conditional to check player1's health and display an appropriate message.
  11. If player1 was still alive, we used a loop to simulate them taking poison damage until their health was no longer above 0.
  12. When player1's health dropped to 0 or less, we displayed a message after the poison loop saying that they had died from the poison.

With all of the code above, we can create a character, have it take a single instance of damage, take damage over time, heal it, and change the amount of damage it takes!

Now that you've seen a longer chunk of script, a couple of final things to note:

  1. In C++, braces define blocks of code, such as classes, functions, conditionals, and loops. Indentation helps make the structure easier to read, but it does not define the blocks. Most statements end with a semicolon.
  2. In C++, functions can be declared at file scope and classes can contain member functions. A typical program starts running at main, which creates objects and calls functions and methods to perform the program's main tasks.
