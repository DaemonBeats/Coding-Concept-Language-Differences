C#

Welcome to C#! C# is a high-level, statically typed programming language developed by Microsoft. It is commonly used with the .NET platform to build applications for the web, desktop, games, and more.

Comments in C#

In C#, you can add comments (notes that aren't executed by the program, for others looking at your code to read) to your code using two different syntaxes:

  • Single-line comments start with two forward slashes (//) and continue to the end of the line.
  • Multi-line comments start with a forward slash and an asterisk (/*) and end with an asterisk and a forward slash (*/).

Variables

In C#, each variable has a declared type that determines what kind of value it can hold. C# is statically typed, so a variable's type is determined at compile time and cannot be changed by assigning it a value of another type. You can write the type explicitly or use var to let the compiler infer it from the initial value.

Declaring Numbers

In C#, you declare a variable's type before assigning a number to it:

Int: int x = 5;

Decimal (double): double x = 5.0;

int and double are value types. C# also has other numeric types, such as float and decimal, which represent different levels of precision for a decimal number.

Declaring Strings

Strings in C# are sequences of characters enclosed in double quotes. The built-in string type represents text.

String: string x = "Hello, World!";

Note: unlike Python, single quotes are used for individual char values, such as char letter = 'A';.

Declaring Booleans

Booleans in C# represent the truth values true and false. The values are lowercase, and a variable is declared with the type bool.

True: bool x = true;

False: bool x = false;

Null Values

In C#, null means that a reference does not refer to an object. With nullable reference types enabled, add ? to a reference type that is allowed to hold null. Value types can also be made nullable with ?.

Nullable reference: string? x = null;

Nullable value type: int? x = null;

null is not the same as 0 or an empty string; it represents the absence of a value or object reference.

Type Changing

C# is statically typed, which means a variable's type cannot be changed by assigning a value of another type. You can convert a value itself to another type.

Widening: Converting a smaller numeric type to a larger one (e.g., int to double): double x = 5; stores the value as 5.0 instead of 5.

Narrowing: Converting a larger numeric type to a smaller one (e.g., double to int) may lose information. int x = (int)5.8; truncates the decimal part, resulting in 5 and the loss of the .8.

Converting text to a number: int x = int.Parse("5"); converts the string "5" to the integer 5. For decimal values, use double.Parse("5.0"). Parsing can fail if the text is not a valid number; methods such as int.TryParse can be used to handle invalid input.

Input/Output

Input

C# uses the Console class for basic text input and output. The Console.ReadLine() method reads a line of text from the user:

string name = Console.ReadLine();

To prompt the user first, write a message without ending the line:

Console.Write("What is your name? ");
string name = Console.ReadLine();

This displays "What is your name? ", reads a line from the user, and assigns that text to name. Since name is a string, assigning another line of text to it later would replace its current value.

Console.ReadLine() returns text, so convert it when you need a number. This example assumes the user enters valid numeric text:

Console.Write("What is your age? ");
int age = int.Parse(Console.ReadLine());

Static Output

The Console.WriteLine() method displays output and then moves to a new line:

Console.WriteLine("Hello, World!");

The above example displays the text "Hello, World!" to the user.

Variable Output

You can also use Console.WriteLine() to display the value of a variable:

string name = "Alice";
Console.WriteLine(name);

The above example displays the value of name, which is "Alice".

Static + Variable Output

You can combine static text with variable values using string interpolation. Place a $ before the opening quote and put variable names inside braces:

string name = "Alice";
Console.WriteLine($"Hello, {name}!");

The above example displays "Hello, Alice!".

Newlines

Console.WriteLine() adds a newline after its output. Console.Write() does not, so subsequent output continues on the same line:

Console.WriteLine("Hello, World!");
Console.WriteLine("How are you?");

This displays "Hello, World!" on one line and "How are you?" on the next line. You can also use the \n escape sequence within a string:

Console.WriteLine("Hello, World!\nHow are you?");

Long expressions can be split across source lines while remaining one statement, as long as the statement ends with a semicolon:

int x = (
    number1
    + number2
); // this is all one statement, since there's no semicolon until the end

C# uses semicolons to end most statements. Whitespace and newlines do not, by themselves, end a statement.

Conditionals

Conditionals in C# execute different blocks of code based on conditions. The most common conditional statement is the if statement:

int age = 18;
if (age >= 18) {
    Console.WriteLine("You are an adult.");
}

This displays "You are an adult." if age is greater than or equal to 18. C# places the condition in parentheses and uses braces ({}) to mark the block.

Conditional Operators

C# provides several comparison operators that can be used with if statements:

  • ==: Equal to
  • !=: Not equal to
  • >: Greater than
  • <: Less than
  • >=: Greater than or equal to
  • <=: Less than or equal to

The equality operator uses two = signs. A single = assigns a value rather than comparing values:

int age = 18;
if (age == 18) {
    Console.WriteLine("Age is 18");
}
age = 18;

The if condition checks whether age is 18, while the final line assigns 18 to age. These are separate statements.

Else and Else If Statements

C# uses else and else if to handle multiple conditions:

int age = 17;
if (age >= 18) {
    Console.WriteLine("You are an adult.");
} else {
    Console.WriteLine("You are not an adult.");
}

The else block executes if the condition in the if statement is false.

int score = 85;
if (score >= 90) {
    Console.WriteLine("Grade: A");
} else if (score >= 80) {
    Console.WriteLine("Grade: B");
} else {
    Console.WriteLine("Grade: C");
}

The else if block checks another condition if earlier conditions were false. Once an if or else if condition is true, the remaining branches in that conditional chain are skipped.

Combining Conditions

C# provides logical operators to combine multiple conditions:

  • &&: Both conditions must be true
  • ||: At least one condition must be true
  • !: Negates the condition
int age = 18;
bool hasLicense = true;
if (age >= 18 && hasLicense) { // checks if both conditions are true
    Console.WriteLine("You can drive.");
}

For &&, both conditions must be true; for ||, at least one must be true. The ! operator negates a condition. You can combine these operators to create more complex conditions.

Single-Statement If

If an if branch contains one statement, braces may be omitted, though using braces can make the code clearer and help prevent mistakes:

if (age >= 18)
    Console.WriteLine("You are an adult.");

Ternary Operator

C# provides a ternary operator for simple conditional expressions and assignments:

int age = 18;
string status = age >= 18 ? "adult" : "not adult";

This assigns "adult" to status if age is greater than or equal to 18; otherwise, it assigns "not adult". You can also use the ternary expression directly in a return statement inside a class method:

class Example {
    static string GetStatus(int age) {
	   return age >= 18 ? "adult" : "not adult";
    }
}

This method takes an age and returns the appropriate status based on the condition.

Switch Statements

C# uses the switch statement to select between a set of values:

int statusCode = 404;
switch (statusCode) {
    case 200:
	   Console.WriteLine("OK");
	   break;
    case 404:
	   Console.WriteLine("Not Found");
	   break;
    default:
	   Console.WriteLine("Unknown Status");
	   break;
}

The switch statement checks statusCode and executes the matching case. The break statements leave the switch after a case executes, and default handles values not listed. A switch is useful for a limited set of specific values; use if/else if for more complex conditions.

Loops

Loops execute a block of code repeatedly. C# provides foreach, for, and while loops.

Foreach Loop

The foreach loop iterates over each element in a sequence, such as an array or collection:

string[] fruits = { "apple", "banana", "cherry" };
foreach (string fruit in fruits) {
    Console.WriteLine(fruit);
}

In simpler terms, this says "for each fruit in the sequence of fruits, print that specific fruit before moving on to the next one." The loop variable fruit takes on each element's value during an iteration. It can technically have another name, but descriptive names make code easier to understand.

Example of a bad loop variable name:

foreach (string x in fruits) {
    Console.WriteLine(x);
}

While this works, using a more descriptive name like fruit makes the code more readable and maintainable.

For Loop with a Counter

A traditional for loop can repeat a block while counting through a range of numbers:

for (int i = 0; i < 5; i++) {
    Console.WriteLine(i);
}

This prints the numbers 0 through 4. The three parts of the loop header initialize i, check the condition before each iteration, and increment i after each iteration. The stop value 5 is not printed because the condition is i < 5. You can change the starting value and increment:

for (int i = 2; i < 10; i += 2) {
    Console.WriteLine(i);
}

This prints 2, 4, 6, and 8, counting up to 10 (not including 10) in steps of 2.

While Loop

The while loop executes a block repeatedly as long as its condition is true:

int i = 0;
while (i < 5) {
    Console.WriteLine(i);
    i++;
}

This is basically saying: "while i is less than 5, print the value of i, then increase it by 1." The variable must be initialized before the loop and updated so that the loop can eventually end.

Loop Control Statements

C# provides control statements to manage the flow of loops:

  • break: Terminates the loop immediately.
  • continue: Skips the rest of the current iteration and moves to the next one.
for (int num = 1; num < 10; num++) {
    if (num == 3) {
	   continue;
    }
    if (num == 6) {
	   break;
    }
    Console.WriteLine(num);
}

The loop starts with num equal to 1 and prints 1, 2, 4, and 5. continue skips 3, and break ends the loop when num reaches 6. The condition num < 10 means the loop stops before 10.

Methods

Methods in C# are reusable blocks of code declared inside a class or another type. Methods can receive input through parameters and may return a value. C# requires a return type; use void when a method does not return a value. Unlike Python, C# does not have standalone functions at the top level in the traditional class-based model.

Methods Without Parameters

Methods without parameters have an empty set of parentheses:

class Example {
    static void Greet() {
	   Console.WriteLine("Hello, World!");
    }

    static void Main() { // Main denotes the entry point of the program, and is where the program starts executing.
	   Greet();
    }
}

The method called Greet prints "Hello, World!" each time it is called. It is declared static so Main can call it directly on the class.

Methods with Parameters

Parameters let a method receive values. In C#, each parameter must have a declared type. Parameters are the variables in the method signature; arguments are the values passed when calling the method.

class Example {
    static void Greet(string name) {
	   Console.WriteLine($"Hello, {name}!");
    }

    static void Main() {
	   Greet("Alice");
    }
}

Here, name is a string parameter. Calling Greet("Alice") passes the string "Alice" as an argument, so the method prints "Hello, Alice!".

You can call a method more than once with different arguments:

Greet("Alice");  // Output: Hello, Alice!
Greet("Bob");    // Output: Hello, Bob!

You can also store an argument in a variable and pass that variable to the method:

string name = "Alice";
Greet(name);  // Output: Hello, Alice!

Return

A method can return a value to the code that called it. Its declared return type must match the type of the value it returns:

class Example {
    static int Add(int a, int b) {
	   return a + b;
    }

    static void Main() {
	   int result = Add(3, 5);  // result is now 8
	   Console.WriteLine(Add(3, 5));  // Output: 8
    }
}

The Add method takes two int parameters and returns their sum. You can store the returned value or use it directly in an expression.

Classes and Objects

In C#, methods package reusable behavior, while classes define a kind of object and provide a way to create instances of it. A class is a blueprint for creating objects, while an object is an instance of a class. For example, a Dog class can define information each dog object stores:

class Dog {
    public string Name;
    public string Breed;

    public Dog(string name, string breed) { // this is the constructor
	   Name = name;
	   Breed = breed;
    }
}

class Example {
    static void Main() {
	   Dog myDog = new Dog("Doge", "Shiba Inu");
    }
}

The Dog class has two fields, Name and Breed. Its constructor, also named Dog, runs when a new Dog object is created with new. The myDog variable refers to an instance initialized with the name "Doge" and breed "Shiba Inu". You can create other Dog objects with different values.

Each Dog object has its own Name and Breed values. You could create a Dog named Bobby that is a golden retriever, or another named Scout that is a corgi.

In a constructor, the parameters provide the initial values for the new object. Here, Name = name; assigns the parameter name to the object's Name field. C# distinguishes these names by capitalization.

Classes and objects are central to object-oriented programming (OOP) in C# and can help organize related data and behavior.

Summary + Combined Examples

Now let's combine each concept we've learned into one code block. Let's say that I want to create a program that will be used to manage a character in a fantasy game, keeping track of their health, mana, and what would happen if they got attacked.

You can click on the comparison buttons to see how the syntax differs between C# and the other languages on this site.

using System;

// Creating a class:
class Character {
    public string Name;
    public int Health;
    public int Mana;

    public Character(string name, int health, int mana) { // uses a constructor to initialize the Character object with a name, health, and mana. What their name is and how much health and mana they have will be decided when we create the character by passing arguments to the constructor.
	   Name = name;
	   Health = health;
	   Mana = mana;
    }

// Creating a method (a function within a class):
    public void TakeDamage(int damage) {
	   Health -= damage; // this line reduces the Character's health by the amount of damage taken. The -= operator is a shorthand for Health = Health - damage.
    }
}

class Example {
// Creating a method to heal a character:
    static void Heal(Character character, int amount) {
	   character.Health += amount; // this line increases the character's health by the specified amount.
    }

    static void Main() {
// Declaring a variable:
	  int takeThisMuchDamage = 0;

// Creating an object using a class:
	   Character player1 = new Character("Alice", 100, 50);

// Input:
	   Console.Write("How much damage should the character take? ");
	   takeThisMuchDamage = int.Parse(Console.ReadLine()!); // we read user input as text, convert it to an integer, and assign it to takeThisMuchDamage. For this example, assume the user enters a valid number >= 0.

// Calling an object's method, using the variable we declared earlier:
	   player1.TakeDamage(takeThisMuchDamage);

// Method call:
	   Heal(player1, 20);

// Output:
	   Console.WriteLine($"{player1.Name} has {player1.Health} health and {player1.Mana} mana.");

// Conditional:
	   if (player1.Health > 10) {
		  Console.WriteLine($"Congrats! {player1.Name} is still alive!"); // if the character's health is more than 10, this will trigger and the rest of the if/else if/else block will be skipped.
	   } else if (player1.Health > 0) { // this will trigger if the character's health is greater than 0 but not greater than 10.
		  Console.WriteLine($"{player1.Name} is critically injured. Be Careful!");
	   } else {
		  Console.WriteLine("Your character has died. Game over."); // this will trigger at any point where health is less than or equal to 0, since all other possible health amount conditions have already been checked.
	   }

// Loops:
	   // Let's say that the character is poisoned, and will take damage over time:
	   if (player1.Health > 0) {
		  while (player1.Health > 0) { // while the character's health is greater than 0, this loop will continue to run.
			 player1.TakeDamage(5); // the character takes 5 damage each iteration of the loop.
			 Console.WriteLine($"{player1.Name} takes 5 poison damage and now has {player1.Health} health."); // this output occurs each time the loop repeats.
		  }
		  Console.WriteLine("Your character has died from the poison."); // this line runs after the loop ends because the loop condition is no longer true.
	   }
    }
}

Let's explain what we did above:

  1. We created a Character class with a name, health, and mana.
  2. We made a method inside the class so that any Character could take damage.
  3. We created a Heal method that increases a character's health by the amount passed in when called.
  4. We declared and initialized takeThisMuchDamage so that we could assign it a value later based on user input. In C#, the variable has a declared type and must be assigned before it is used.
  5. We created a Character object named player1, with the name "Alice", 100 health, and 50 mana.
  6. We took input from the user, converted it to an integer, and assigned it to takeThisMuchDamage.
  7. We called the TakeDamage method on player1, using the amount specified by the user's input.
  8. We called the Heal method to heal player1 by 20.
  9. We displayed player1's current health and mana.
  10. We used a conditional to check player1's health and display an appropriate message.
  11. If player1 was still alive, we used a loop to simulate them taking poison damage until their health was no longer above 0.
  12. When player1's health dropped to 0 or less, we displayed a message after the poison loop saying that they had died from the poison.

With all of the code above, we can create a character, have it take a single instance of damage, take damage over time, heal it, and change the amount of damage it takes!

Now that you've seen a longer chunk of script, a couple of final things to note:

  1. In C#, braces define blocks of code, such as classes, methods, conditionals, and loops. Indentation helps make the structure easier to read, but it does not define the blocks. Most statements end with a semicolon.
  2. In C#, methods are declared inside classes. A program's Main method is its entry point; it can create objects and call methods to perform the program's main tasks.
