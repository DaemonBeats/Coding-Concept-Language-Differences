Python

Welcome to Python! Python is a high-level, interpreted programming language known for its simplicity and readability and is often used for web development, data analysis, artificial intelligence, and more.

Comments in Python

In Python, you can add comments (notes that aren't executed by the program, for others looking at your code to read) to your code using the following syntax:

  • Single-line comments start with a hash symbol (#) and continue to the end of the line.
  • Python does not have a separate multi-line comment syntax. To comment out multiple lines, start each line with a hash symbol (#). Triple-quoted strings ("""documentation""" or '''documentation''') are sometimes used for documentation over multiple lines, but they are strings rather than comments.

Variables

In Python, variable names refer to values, and each value has a type. When you assign a value to a name, Python automatically determines that value's type. Because Python is dynamically typed, you can later assign a value of a different type to the same name.

Declaring numbers

In Python, you can assign a numeric value to a variable without declaring its type first, like x = 5. Python determines the value’s type from what you assign (dynamic typing).

Int: x = 5

Float: x = 5.0

Declaring Strings

Strings in Python are sequences of characters enclosed in quotes. You can create a string by enclosing text in single or double quotes.

Single quotes: x = 'Hello, World!'

Double quotes: x = "Hello, World!"

Declaring Booleans

Booleans in Python represent the truth values True and False.

True: x = True

False: x = False

Note that the first letter is capitalized.

Null Value Declaration

In Python, you can assign the null value (None) to a variable using the keyword None. You might do this to indicate that the variable does not currently refer to a meaningful value.

None: x = None

Note that None (capitalized) is not the same as 0 or an empty string; it represents the absence of a value.

Type Changing

Python is dynamically typed, which means you can change the type of a variable at any time by assigning it a new value of a different type.

For example, you can start with an integer:

x = 5

And then change it to a string:

x = "Hello, World!"

x will now hold a string value, and will no longer hold the int value of 5.

Input/Output

Input

Python provides built-in functions for input and output operations. The input() function is used to read input from the user, and the print() function is used to display output.

name = input("What is your name? ")

In the example above, the program will display "What is your name?", then take the input from the user and assign it to the variable name. Note that in this example we're also declaring name as a new variable. If we had already declared name before, it'd simply be replaced with the new input value.

Note that the input() function always returns a string, so if you need to convert it to another type (e.g., an integer), you'll need to use a conversion function:

age = int(input("What is your age? "))

Static Output

The print() function is used to display output to the user.

print("Hello, World!")

The above example will display the text "Hello, World!" to the user.

Variable Output

You can also use the print() function to display the value of a variable:

name = "Alice"
print(name)

The above example will display the value of the variable name, which is "Alice".

Static + Variable Output

You can also combine static text with variable values in the print() function:

name = "Alice"
print(f"Hello, {name}!")

The above example will display the text "Hello, Alice!" to the user. Combining static text and variables in Python uses f-strings, which are prefixed with an f before the opening quote, and use {} to embed variable values.

Newlines

In Python, newlines are handled automatically when using the print() function. Each call to print() will output text followed by a newline character, so subsequent calls will appear on a new line.

print("Hello, World!")
print("How are you?")

This will display "Hello, World!" on one line and "How are you?" on the next line.

Alternatively, you can use the \n escape sequence to insert a newline character within a single print() call:

print("Hello, World!\nHow are you?")

Note: For long expressions in Python that you want to split across multiple lines for readability without Python reading them as multiple commands, you can use parentheses() to group the expression, and Python will allow it to continue on the next line without any special characters.

x = (
number1 
+ number2
)

In the above example, although the expression is split across multiple lines, Python treats it as a single expression due to the parentheses.

Python usually uses newlines to separate statements. Semicolons can separate multiple simple statements on one line, but they are rarely needed.

Conditionals

Conditionals in Python are used to execute different blocks of code based on certain conditions. The most common conditional statement is the if statement.

age = 18
if age >= 18:
    print("You are an adult.")

The above example will display "You are an adult." if the variable age is greater than or equal to 18. Note that at the end of a conditional line, you must have a :

Conditional Operators

Python provides several conditional operators that can be used in conjunction with the if statement:

  • ==: Equal to
  • !=: Not equal to
  • >: Greater than
  • <: Less than
  • >=: Greater than or equal to
  • <=: Less than or equal to

Note that the equality operator uses two = signs. A single = assigns a value rather than comparing values.

if age == 18:
    print("Age is 18")
age = 18

In the above block, the first line would check if age is 18, while the third sets age's value to 18 (the two statements are not connected).

Else and Elif Statements

Python also provides else and elif statements to handle multiple conditions:

age = 17
if age >= 18:
    print("You are an adult.")
else:
    print("You are not an adult.")

The else block is executed if the condition in the if statement is false.

score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")

The elif block allows you to check additional conditions if the previous conditions are false. In Python, if an if/elif statement is found true, then the rest of the if/elif/else block will be skipped after executing the code inside the statement that triggered true.

Combining Conditions

Python also provides logical operators to combine multiple conditions:

  • and: Both conditions must be true
  • or: At least one condition must be true
  • not: Negates the condition
age = 18
has_license = True
if age >= 18 and has_license:
    print("You can drive.")

For the and operator, both conditions must be true for the block to execute. For the or operator, at least one condition must be true. For the not operator, the condition is checked for falsity (for example, if we had x = 5 and if not x == 5, the if statement would evaluate to False and not trigger). You may have any combination and number of these operators to create complex conditions.

Shorthand If

Python also provides a shorthand syntax for simple if statements that have only one statement to execute:

if age >= 18: print("You are an adult.")

Ternary Operator

Python also provides a ternary operator for simple conditional assignments:

age = 18
status = "adult" if age >= 18 else "not adult"

The above example assigns "adult" to the variable status if the variable age is greater than or equal to 18, otherwise it assigns "not adult". You can also directly return the result of the ternary operator in a function instead of assigning it to a variable:

def get_status(age):
    return "adult" if age >= 18 else "not adult"

Functions are covered further down, but what this is doing is taking an age variable, giving it to the function get_status, and returning the appropriate status based on the condition.

Matching

In python, matching is done using the match statement, which is similar to a switch statement in other languages:

status_code = 404
match status_code:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case _:
        print("Unknown Status")

In the above example, the match statement checks the value of status_code and executes the corresponding case block. The underscore _ acts as a wildcard that matches any value not explicitly handled by the previous cases. Match is better used when checking for limited specific values, otherwise it's more common to use if/elif statements.

Loops

Loops are used to execute a block of code repeatedly. Python provides two main types of loops: for and while.

For Loop

The for loop in Python is used to iterate over a sequence (such as a list, tuple, or string):

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

In simpler terms, the above is saying "for each fruit in the list of fruits, print that specific fruit before moving on to the next one in the list". In the for statement itself, the singular term fruit is the name for the new loop variable that takes on the value of each element in the sequence during each iteration. It can technically be anything, but it's best to make it describe whatever it's representing:

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

Also valid, but not as descriptive:

fruits = ["apple", "banana", "cherry"]
for x in fruits:
    print(x)

Note that the for statement, like the if statement, ends with a colon (:)

For Loop with Range

The for loop can also be used with the range() function to iterate over a sequence of numbers:

for i in range(5):
    print(i)

This will print the numbers 0 through 4. The range() function generates a sequence of numbers from 0 to the specified number in range (not including the specified number itself.) You can also dictate the increment at which i increases, as well as where it starts from, using the pattern (start, end (not included), increment amount):

for i in range(2, 10, 2):
    print(i)

This will print the numbers 2, 4, 6, and 8, counting up to 10 (not including 10), in steps of 2.

While Loop

The while loop in Python is used to execute a block of code repeatedly as long as a condition is true:

i = 0
while i < 5:
    print(i)
    i += 1

What's going on here is basically: "while i is less than 5, print the value of i, then increase i by 1". Note that when using while loops, i (or whatever variable is used) must be initialized before the loop.

Loop Control Statements

Python provides several control statements to manage the flow of loops:

  • break: Terminates the loop immediately.
  • continue: Skips the rest of the current iteration and moves to the next one.
for num in range(1, 10):
    if num == 3:
        continue
    if num == 6:
        break
    print(num)

The loop starts with num equal to 1 and prints 1, 2, 4, and 5. continue skips 3, and break ends the loop when num reaches 6. The stop value 10 is excluded from range.

Else Clause in Loops

The else clause can be used with both for and while loops. It runs when the loop finishes without encountering break:

for i in range(5):
    print(i)
else:
    print("Loop finished")

Code in the else block will execute only if the loop completes normally.

Example of when the else statement wouldn't be executed:

for i in range(5):
    print(i)
    if i == 3:
        break
else:
    print("Loop finished")

When i equals 3, break terminates the loop, so the else block is skipped.

Functions

Functions in Python are used when one expects to use certain blocks of code multiple times, but using different arguments each time. They are defined using the def keyword.

Functions Without Parameters

Functions without parameters are defined with an empty set of parentheses:

def greet():
    print("Hello, World!")

The above creates a function called greet that will always print "Hello, World!" when the function is called, no matter what.

Functions with Parameters

If you want a function to be able to change its output based on an input, we can pass arguments into the function by assigning them a parameter name in the () of the function declaration line:

Note: The terms "parameter" and "argument" are often used interchangeably, but strictly speaking, parameters are the variables defined in the function signature, while arguments are the values passed to the function when it is called.

def greet(name):
    print(f"Hello, {name}!")

In the above block, the function is named greet, and name is its parameter. A function call must provide values for all required parameters, even if the function doesn't use them. Here, greet uses name to build its output.

To call a function, you simply use its name followed by parentheses containing any required parameters:

greet("Alice")  # Output: Hello, Alice!

The above will call the greet function from before, passing in the string "Alice" as the name argument of the function. In other words, "send the string 'Alice' to the greet function and set the function's name parameter to it, then do what the function says".

We can call a function multiple times in a row with different arguments, as each call runs independently:

greet("Alice")  # Output: Hello, Alice!
greet("Bob")    # Output: Hello, Bob!

We can also pre-assign a value to the variable that we pass into the function:

name = "Alice"
greet(name)  # Output: Hello, Alice!

Return

Return statements are used to send a value back to the caller of the function:

def add(a, b):
    return a + b

In the above example, the add function takes two parameters, a and b, and returns their sum. When a function returns a value, you can assign that value to a variable or use it directly in an expression:

result = add(3, 5)  # result is now 8
print(add(3, 5))     # Output: 8

Classes and Objects

In Python, functions package reusable behavior, while classes define a kind of object and provide a way to create instances of it. A class is a blueprint for creating objects, while an object is an instance of a class. For example, you could have a class named Dog and create a Dog object called my_dog:

class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

my_dog = Dog("Doge", "Shiba Inu")

In the above example, the Dog class has an __init__ method that initializes each Dog object with a name and breed attribute. The my_dog object is an instance of the Dog class, initialized with the name "Doge" and breed "Shiba Inu". In other words, all Dogs will have a name and breed, which you pass in as arguments when you create an instance (object) of the class.

In simpler terms, every Dog object will have a name and breed attribute, but different Dogs will have different values for those attributes. I could make a Dog that's named Bobby that's a golden retriever, or another Dog that's named Scout and is a corgi.

*A method is like a function, but it belongs to a class instead of being standalone.

The self parameter refers to the specific Dog object being initialized. When you create a Dog, Python passes that object to __init__ as self. Then self.name = name stores the supplied name on that object. It's like the object being initialized is saying "oh, the name of myself? It's equal to (the name that you passed in)."

Classes and Objects are the foundation of object-oriented programming (OOP) in Python. OOP does a lot to help keep code organized and maintainable.

Summary + Combined Examples

Now let's combine each concept we've learned into one code block. Let's say that I want to create a script that will be used to manage a character in a fantasy game, keeping track of their health, mana, and what would happen if they got attacked.

You can click on the comparison buttons to see how the syntax differs between Python and the other languages on this site.

# Creating a class:
class Character: # creates a class named Character, meaning that we can make multiple different Characters that have the same properties.

	def __init__(self, name, health, mana): # uses __init__ to initialize the Character object with a name, health, and mana.
		self.name = name
		self.health = health
		self.mana = mana

	# Creating a method (a function within a class):
	def take_damage(self, damage):
		self.health -= damage # this line reduces the Character's health by the amount of damage taken. The -= operator is a shorthand for self.health = self.health - damage.


# Creating a function:
def heal(character, amount): # this function will take a character object and an amount of health to heal them for. It will increase the character's health by the specified amount.
     character.health += amount


# Declaring a variable:
takeThisMuchDamage = None # we set the variable's value to None (which is of type NoneType), so that we can assign a value to it later based on user input.

# Creating an object using a class:
player1 = Character("Alice", 100, 50) # we create a Character object named player1 with the name "Alice", 100 health, and 50 mana.

# Input:
takeThisMuchDamage = int(input("How much damage should the character take? ")) # we use the input() function to get user input, and convert it to an integer using int(). We can change the type of the variable thanks to Python's dynamic typing. For now, we assume that the user will input a valid number >= 0.

# Calling an object's method, using the variable we declared earlier:
player1.take_damage(takeThisMuchDamage) # Python passes the object as self automatically, so only the damage argument is supplied.

# Function call:
heal(player1, 20) # we call the heal function, passing in player1 and 20 for the amount of health to heal. Notice that functions are called directly by name rather than through an object.

 # Output:
print(f"{player1.name} has {player1.health} health and {player1.mana} mana.") # this will print the character's current health and mana. Notice that when referring to the attributes of an object, we use the object_name.attribute_name, with a period in between the two.

# Conditional:
if player1.health > 10:
     print(f"Congrats! {player1.name} is still alive!") # if the character's health is more than 10, this will trigger and the rest of the if/elif/else block will be skipped.
elif player1.health > 0:
     print(f"{player1.name} is critically injured. Be Careful!")
else:
     print("Your character has died. Game over.") # this will trigger at any point where health is less than or equal to 0, since all other possible health amount conditions have already been checked.

# Loops:
# Let's say that the character is poisoned, and will take damage over time:
if player1.health > 0:
     while player1.health > 0:
		player1.take_damage(5) # the character takes 5 damage each iteration of the loop.
		print(f"{player1.name} takes 5 poison damage and now has {player1.health} health.") # this output occurs each time the loop repeats.
     print("Your character has died from the poison.") # this line runs after the loop ends because the loop condition is no longer true.

Let's explain what we did above:

  1. We created a Character class with a name, health, and mana.
  2. We made a method inside the class so that any Character could take damage.
  3. We created a heal function that increases a character's health by the amount passed in when called.
  4. We declared the variable takeThisMuchDamage with value None so that we could assign it a value later based on user input.
  5. We created a Character object named player1, with the name "Alice", 100 health, and 50 mana.
  6. We took input from the user, converted it to an integer, assigned it to takeThisMuchDamage
  7. We called the take_damage method on player1, using the amount specified by the user's input.
  8. We called the heal function to heal player1 by 20.
  9. We displayed player1's current health and mana.
  10. We used a conditional to check player1's health and display an appropriate message.
  11. If player1 was still alive, we used a loop to simulate them taking poison damage until their health was no longer above 0.
  12. When player1's health dropped to 0 or less, we displayed a message after the poison loop saying that they had died from the poison.

With all of the code above, we can create a character, have it take a single instance of damage, take damage over time, heal it, and change the amount of damage it takes!

Now that you've seen a longer chunk of script, a couple of final things to note:

  1. In Python, we don't use {} to dictate blocks of code, like other languages do. Instead, we use indentation. That's how blocks like functions, classes, methods, and conditionals will know what's a part of them and what's not. We can indent multiple times, like we did in the class. The class had multiple methods that were indented once to show that they were a part of the class, and the content of those methods was indented twice to show that they were a part of the methods.
  2. In Python, classes and functions are typically defined near the beginning of a script so that they can be used later in the program. After these definitions, programmers often create variables, collect user input, create objects, and call functions and methods to perform the program's main tasks.
