Java

Welcome to Java! Java is a high-level, class-based, object-oriented programming language that is designed to have as few implementation dependencies as possible, meaning it can be used to build applications that run on any platform that supports Java.

Comments in Java

In Java, you can add comments (notes that aren't executed by the program, for others looking at your code to read) to your code using two different syntaxes:

  • Single-line comments start with two forward slashes (//) and continue to the end of the line.
  • Multi-line comments start with a forward slash and an asterisk (/*) and end with an asterisk and a forward slash (*/).

Variables

In Java, each variable has a declared type that determines what kind of value it can hold. Primitive types are Java's basic built-in types for simple values, such as whole numbers, decimal numbers, characters, and true-or-false values. You include the type when declaring a variable, and it cannot later be assigned a value of an incompatible type.

Declaring Numbers

In Java, you declare a variable's type before assigning a number to it:

Int: int x = 5;

Decimal (double): double x = 5.0;

int and double are primitive types.

Declaring Strings

Strings in Java are sequences of characters enclosed in double quotes.

String: String x = "Hello, World!";

Note: Unlike Python, Java does not use single quotes for strings; single quotes are used for individual char values (single characters).

Declaring Booleans

Booleans in Java represent the truth values true and false. The values are lowercase, and a variable must be declared with the primitive type boolean.

True: boolean x = true;

False: boolean x = false;

boolean is a primitive type.

Null References

In Java, you can assign null to a reference variable, such as a String, to indicate that it does not currently refer to an object. Primitive variables such as int and boolean cannot be assigned null.

Null reference: String x = null;

null is not the same as 0 or an empty string; it means the reference does not refer to an object.

Type Changing

Java is statically typed, which means that the type of a variable is declared when initialized and cannot be changed, even when assigning new values. However, you can convert a value itself to another type.

Widening: Converting a smaller type to a larger type (e.g., int to double): double x = 5; will result in the value 5.0 instead of 5.

Narrowing: Converting a larger type to a smaller type (e.g., double to int), which may result in loss of precision: int x = (int) 5.8; Here, the decimal part is truncated and lost, resulting in just 5.

Converting text to a number: int x = Integer.parseInt("5"); This will turn the string "5" into the integer 5. This does not work with decimal numbers, however. Instead, you can use Double.parseDouble("5.0") to convert a string to a double.

Input/Output

Input

Java uses classes such as Scanner to read input, and System.out to display output. To read a line of text from the user, import java.util.Scanner, create a Scanner connected to System.in, and call nextLine():

import java.util.Scanner;

Scanner scanner = new Scanner(System.in);
System.out.print("What is your name? ");
String name = scanner.nextLine();

This displays "What is your name? ", reads a line from the user, and assigns that text to the name variable. Since name is declared as a String, assigning another line of text to it later would replace its current value.

To read an integer, use a method such as nextInt():

System.out.print("What is your age? ");
int age = scanner.nextInt();

Static Output

The System.out.println() method displays output followed by a line break:

System.out.println("Hello, World!");

The above example will display the text "Hello, World!" to the user.

Variable Output

You can also use System.out.println() to display the value of a variable:

String name = "Alice";
System.out.println(name);

The above example will display the value of the variable name, which is "Alice".

Static + Variable Output

You can combine static text with a variable value using the + operator:

String name = "Alice";
System.out.println("Hello, " + name + "!");

The above example will display the text "Hello, Alice!" to the user. In Java, the + operator joins strings and other values into one string for output.

Newlines

In Java, each call to System.out.println() ends with a line break, so subsequent calls appear on a new line.

System.out.println("Hello, World!");
System.out.println("How are you?");

This will display "Hello, World!" on one line and "How are you?" on the next line.

Alternatively, you can use the \n escape sequence to insert a line-feed character within a single string:

System.out.print("Hello, World!\nHow are you?");

For a long expression split across multiple lines, Java treats line breaks as whitespace. For example, the expression can continue after an operator:

int number1 = 5;
int number2 = 10;
int sum = number1 +
    number2;

The line break does not end the statement; the semicolon does.

Unlike Python, Java requires a semicolon at the end of most statements. A newline alone does not terminate a statement.

Conditionals

Conditionals in Java execute different blocks of code based on conditions. The most common conditional statement is if.

int age = 18;
if (age >= 18) {
    System.out.println("You are an adult.");
}

This displays "You are an adult." when age is greater than or equal to 18. Java places the condition in parentheses and the block of code in braces.

Conditional Operators

Java provides comparison operators that can be used in conditions:

  • ==: Equal to
  • !=: Not equal to
  • >: Greater than
  • <: Less than
  • >=: Greater than or equal to
  • <=: Less than or equal to

The equality operator uses two = signs. A single = assigns a value rather than comparing values.

if (age == 18) {
    System.out.println("Age is 18");
}
age = 18;

The first statement checks whether age is 18; the last statement assigns 18 to age. For objects such as String, == compares references, not text content; use .equals() to compare string contents.

Else and Else-If Statements

Java uses else and else if to handle alternative conditions:

int age = 17;
if (age >= 18) {
    System.out.println("You are an adult.");
} else {
    System.out.println("You are not an adult.");
}

The else block runs if the if condition is false.

int score = 85;
if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else {
    System.out.println("Grade: C");
}

The else if block checks another condition if the earlier condition was false. Once one branch is taken, the remaining branches in that chain are skipped.

Combining Conditions

Java uses logical operators to combine or negate conditions:

  • &&: Both conditions must be true
  • ||: At least one condition must be true
  • !: Negates a condition
int age = 18;
boolean hasLicense = true;
if (age >= 18 && hasLicense) {
    System.out.println("You can drive.");
}

With &&, both conditions must be true; with ||, at least one must be true. The ! operator reverses a boolean value: for example, !(age == 18) is false when age is 18. You can combine any number of these logic operators in a single statement check.

Single-Statement If

If an if has only one statement, Java allows the braces to be omitted, though braces are often clearer and help prevent mistakes:

if (age >= 18)
    System.out.println("You are an adult.");

Ternary Operator

Java's ternary operator is a nice way to choose between two values based on a condition:

int age = 18;
String status = age >= 18 ? "adult" : "not adult";

This assigns "adult" to status if age is at least 18; otherwise, it assigns "not adult". The expression can also be used in a return statement.

Switch

Java's switch statement selects a branch based on a value, making it useful when checking a variable against several specific values:

int statusCode = 404;
switch (statusCode) {
    case 200:
        System.out.println("OK");
        break;
    case 404:
        System.out.println("Not Found");
        break;
    default:
        System.out.println("Unknown Status");
}

The matching case runs, and default handles values not listed. In this traditional switch form, break exits the switch so execution does not continue into the next case.

Loops

Loops execute a block of code repeatedly. Java provides several loop forms, including for and while loops.

For Loop

Java's enhanced for loop iterates over each element in an array or other iterable collection:

String[] fruits = {"apple", "banana", "cherry"};
for (String fruit : fruits) {
    System.out.println(fruit);
}

Here, fruit is the loop variable. On each loop of the loop, it holds the next element from fruits. Choose a descriptive variable name to make the code easier to understand.

Bad example of a loop variable name:

for (String x : fruits) {
    System.out.println(x);
}

For Loop with Counter

A traditional for loop is useful when you want to count through a range of numbers. Its parts:

  • initialize a counter (int i = 0)
  • check a condition (i < 5, meaning if i is less than 5)
  • update the counter after each iteration (i++ increases i by 1)
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

This prints the numbers 0 through 4. You can set a different starting value and increment:

for (int i = 2; i < 10; i += 2) {
    System.out.println(i);
}

This prints 2, 4, 6, and 8. The loop stops before i reaches 10, increasing by 2 each time.

While Loop

A while loop repeatedly executes its block as long as its condition is true:

int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

This prints the value of i, then increases it by 1 on each iteration. Initialize the counter before the loop and update it inside the loop so the condition eventually becomes false.

Loop Control Statements

Java provides control statements to change how a loop proceeds:

  • break: Ends the loop immediately.
  • continue: Skips the rest of the current iteration and continues with the next one.
for (int num = 1; num < 10; num++) {
    if (num == 3) {
        continue;
    }
    if (num == 6) {
        break;
    }
    System.out.println(num);
}

This prints 1, 2, 4, and 5. continue skips 3, and break ends the loop when num reaches 6.

Classes and Objects

In Java, classes define the structure and behavior of objects. A class is a blueprint for creating objects, and each object is an instance of its class. For example, a Dog class can define the information each dog object stores:

class Dog {
    String name;
    String breed;

    Dog(String name, String breed) {// the constructor
        this.name = name;
        this.breed = breed;
    }
}

class Example {
    public static void main(String[] args) {
        Dog myDog = new Dog("Doge", "Shiba Inu");
    }
}

The Dog class has two fields, name and breed. Its constructor, also named Dog, runs when a new Dog object is created with new. The myDog variable refers to an instance initialized with the name "Doge" and breed "Shiba Inu". You can create other Dog objects with different values.

In the constructor, this refers to the object being initialized. In this.name = name;, the left-side this.name is that object's field, and the right-side name is the constructor parameter passed in. It's as if we were to say "the name of this object is the name that we passed in."

Note that the class Example and the following line containing void main simply represent the main body of a Java script, and isn't exclusive to the creation of the Dog object.

Classes and objects are central to object-oriented programming (OOP) in Java and can help organize related data and behavior.

Methods

Methods are reusable blocks of code declared inside a class. A method can receive input through parameters and may return a value. Java requires each method to declare a return type; use void when it does not return a value.

Methods Without Parameters

A method without parameters has empty parentheses. This example defines and calls a method that prints a greeting:

class Example {
    static void greet() {
        System.out.println("Hello, World!");
    }

    public static void main(String[] args) {
        greet();
    }
}

The method called greet prints "Hello, World!" each time it is called. It is declared static so main can call it directly on the class.

Methods with Parameters

Parameters let a method receive values. In Java, each parameter must have a declared type:

class Example {
    static void greet(String name) {
        System.out.println("Hello, " + name + "!");
    }

    public static void main(String[] args) {
        greet("Alice");
    }
}

Here, name is a String parameter. Calling greet("Alice") passes the string "Alice" as an argument, so the method prints "Hello, Alice!".

Note that the void main line is just the main body of the Java script, where the code execution statements are put, and is not exclusive to method calls.

You can call a method more than once with different arguments:

greet("Alice");  // Output: Hello, Alice!
greet("Bob");    // Output: Hello, Bob!

You can also store an argument in a variable and pass that variable to the method:

String name = "Alice";
greet(name);  // Output: Hello, Alice!

Return

A method can return a value to the code that called it. Its declared return type must match the type of value it returns:

class Example {
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) { // this line marks the start of the main body
        int result = add(3, 5);  // result is now 8
        System.out.println(add(3, 5));  // Output: 8
    }
}

The add method takes two int parameters and returns their sum. You can store the returned value (like we did with int result) or use it directly (outputted the returned result directly without assigning it to a variable).

Summary + Combined Examples

Now let's combine each concept we've learned into one code block. Let's say that I want to create a script that will be used to manage a character in a fantasy game, keeping track of their health, mana, and what would happen if they got attacked.

You can click on the comparison buttons to see how the syntax differs between Java and the other languages on this site.

import java.util.Scanner;

// Creating a class:
class Character {
    String name;
    int health;
    int mana;

    Character(String name, int health, int mana) { // uses a constructor to initialize the Character object with a name, health, and mana. What their name is and how much health and mana they have will be decided when we create the character by passing arguments to the constructor.
	   this.name = name;
	   this.health = health;
	   this.mana = mana;
    }

// Creating a method:
    void takeDamage(int damage) {
	   this.health -= damage; // this line reduces the Character's health by the amount of damage taken. The -= operator is a shorthand for this.health = this.health - damage.
    }
}

class Example {
// Creating a method to heal a character:
    static void heal(Character character, int amount) {
	   character.health += amount; // this line increases the character's health by the specified amount.
    }

    public static void main(String[] args) { // this line marks the start of the main body of the script, where the code execution statements are put. The main method is the entry point of a Java program.
// Declaring a variable:
	  int takeThisMuchDamage;

// Creating an object using a class:
	   Character player1 = new Character("Alice", 100, 50);

// Input:
	   Scanner scanner = new Scanner(System.in);
	   System.out.print("How much damage should the character take? ");
	   takeThisMuchDamage = scanner.nextInt(); // we use Scanner to get user input as an integer and assign it to takeThisMuchDamage. For this example, assume the user enters a valid number >= 0.

// Calling an object's method, using the variable we declared earlier:
	   player1.takeDamage(takeThisMuchDamage);

// Method call:
	   heal(player1, 20);

// Output:
	   System.out.println(player1.name + " has " + player1.health + " health and " + player1.mana + " mana.");

// Conditional:
	   if (player1.health > 10) {
		  System.out.println("Congrats! " + player1.name + " is still alive!"); // if the character's health is more than 10, this will trigger and the rest of the if/else-if/else block will be skipped.
	   } else if (player1.health > 0) { // this will trigger if the character's health is greater than 0 but not greater than 10.
		  System.out.println(player1.name + " is critically injured. Be Careful!");
	   } else {
		  System.out.println("Your character has died. Game over."); // this will trigger at any point where health is less than or equal to 0, since all other possible health amount conditions have already been checked.
	   }

// Loops:
	   // Let's say that the character is poisoned, and will take damage over time:
	   if (player1.health > 0) {
		  while (player1.health > 0) { // while the character's health is greater than 0, this loop will continue to run.
			 player1.takeDamage(5); // the character takes 5 damage each iteration of the loop.
			 System.out.println(player1.name + " takes 5 poison damage and now has " + player1.health + " health."); // this output occurs each time the loop repeats.
		  }
		  System.out.println("Your character has died from the poison."); // this line runs after the loop ends because the loop condition is no longer true.
	   }
    }
}

Let's explain what we did above:

  1. We created a Character class with a name, health, and mana.
  2. We made a method inside the class so that any Character could take damage.
  3. We created a heal method that increases a character's health by the amount passed in when called.
  4. We declared the variable takeThisMuchDamage so that we could assign it a value later based on user input. In Java, the variable has a declared type and must be assigned before it is used.
  5. We created a Character object named player1, with the name "Alice", 100 health, and 50 mana.
  6. We took input from the user, read it as an integer, and assigned it to takeThisMuchDamage.
  7. We called the takeDamage method on player1, using the amount specified by the user's input.
  8. We called the heal method to heal player1 by 20.
  9. We displayed player1's current health and mana.
  10. We used a conditional to check player1's health and display an appropriate message.
  11. If player1 was still alive, we used a loop to simulate them taking poison damage until their health was no longer above 0.
  12. When player1's health dropped to 0 or less, we displayed a message after the poison loop saying that they had died from the poison.

With all of the code above, we can create a character, have it take a single instance of damage, take damage over time, heal it, and change the amount of damage it takes!

Now that you've seen a longer chunk of script, a couple of final things to note:

  1. In Java, braces define blocks of code, such as classes, methods, conditionals, and loops. Indentation helps make the structure easier to read, but it does not define the blocks.
  2. In Java, classes and methods are declared inside classes. The main method contains the statements that run the program, and it can create objects and call methods declared in the class.
